# 🎮 Day 20 - AI Face Puzzle Game

## 📌 Project Overview

Built an interactive **AI Face Puzzle Game** that transforms a webcam-captured photo into a playable puzzle. Users can choose different difficulty levels, solve the puzzle using drag-and-drop interactions, and track their performance through a timer and move counter.

## 🚀 Features

* 📸 Live Webcam Access
* 🖼️ Photo Capture using Camera
* 🧩 Dynamic Puzzle Generation
* 🎯 Multiple Difficulty Levels (3×3, 4×4, 5×5)
* 🖱️ Drag-and-Drop Puzzle Controls
* ⏱️ Real-Time Timer
* 🔢 Move Counter
* ✅ Correct Piece Detection
* 🏆 Local Leaderboard
* 📱 Responsive Design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Canvas API
* MediaDevices API
* Local Storage
